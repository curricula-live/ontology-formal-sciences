# openmath

complete repository archive; extract symbols, descriptions and dictionary membership from all 216 official, experimental and contributed CDs.

Upstream: https://codeload.github.com/OpenMath/CDs/tar.gz/cbf607561e3f90630ce7a57fe9a85f5bc0dfdd3c

Attribution: OpenMath Society and dictionary authors. Terms: per dictionary. See source.yaml for acquisition details and ingestion.json, when present, for the measured graph size.

The formal-property review uses a file-level derivative-work permission
check in the pinned archive. Curricula's RDF assertions are a derived
representation. They credit the OpenMath Society and dictionary authors,
and cite the original content dictionary for each accepted expression.
The scoped evidence and rejection decisions are described in the
[OpenMath property profile](../../docs/openmath-formal-properties.md).
