## Formal sciences v1.0.0-rc.1 Foundation candidate

This branch prepares the first standalone RDF import candidate under
`curricula.rdf-release/v1`. The package retains the four logical named
graphs, canonical IRIs, reviewed mappings and scientific review history.
This stage concentrates on dependable consumption and owner review.

- The producer validates additive candidate and rights metadata. Consumers
  pin the commit and manifest digest and control storage and activation.
- The identity ledger covers deprecation, replacements, merges and splits.
  Existing A* identifiers are still resolvable.
- Optional, evidence-backed scientific roles distinguish algorithms from
  implementations, methods from problems, and results from premises.
- The transition-matrix carrier classification uses SKOS hierarchy.
  Provenance retains the superseded interpretation and prior module digest.
- The reference consumer exercises package integrity, atomic activation,
  repeated loading, replacement, and rollback. The disposable real
  Fuseki/TDB2 rehearsal covers the same candidate bytes.
- The coverage and review packets describe source scope, provenance and
  limitations. Independent scientific verdicts and owner rights review
  remain open.

evidence, and the ordered verification commands. This text is a draft for
